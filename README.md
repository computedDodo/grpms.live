# GRPMS V2 — Grade & Result Processing Management System

A multi-school academic result management system built with Flask.
Designed for non-technical staff — mobile-first, role-based, with a
physical coupon system for fee enforcement.

---

## Role Hierarchy

```
PlatformAdmin          → Manages all schools, generates all coupon codes
  └── SuperAdmin       → Owns one school, manages all staff within it
        ├── Admin      → Day-to-day school operations (students, classes, subjects)
        ├── Cashier    → Coupon distribution, result release control
        ├── FormMaster → Class rankings, promotions, automated remarks
        ├── Teacher    → Score entry for assigned subjects
        └── Student    → Views results (requires termly coupon activation)
```

---

## Coupon System

**Termly Coupons** — Generated by Platform Admin per school, per term.
Physical codes distributed by Cashier to students after fees are paid.
Each code unlocks one student's report card for that term permanently.
Codes expire automatically when the active term changes.

**Transcript Coupons** — Generated by Platform Admin per student.
Permanent lifetime key. Required to download (not view) a transcript.
Assigned once, never changes, never expires.

## Quick Start (Local Development)

```bash
# 1. Clone and enter the project
git clone <your-repo-url>
cd grpms_v2

# 2. Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Set up environment
cp .env.example .env
# Edit .env and set a real SECRET_KEY

# 5. Verify file structure
python3 verify_structure.py

# 6. Initialize the database
flask db upgrade

# 7. Create your Platform Admin account (interactive)
flask seed-platform-admin

# 8. (Optional) Load demo school with sample data
flask seed-demo-school

# 9. Run the development server
flask run
# → Open http://localhost:5000
```

## First Steps After Login

1. **Platform Admin** → Add School → Create SuperAdmin
2. **SuperAdmin** → School Settings (upload logo/signature/stamp) → Academic Setup (create session + terms, set active) → Create Staff
3. **Admin** → Add Classes → Add Subjects → Enroll Students → Assign Subjects to Teachers → Assign Form Masters
4. **Platform Admin** → Generate Coupons (select school + active term + quantity)
5. **Cashier** → Print unused coupon list → Distribute physically
6. **Teacher** → Enter Scores
7. **Cashier** → Release Results per class
8. **Student** → Login → Enter coupon code → View & download report card

## Production Deployment

1. Set `FLASK_ENV=production` in `.env`
2. Set a strong `SECRET_KEY` (e.g. `python3 -c "import secrets; print(secrets.token_hex(32))"`)
3. Set `DATABASE_URL` to your PostgreSQL/MySQL connection string
4. Uncomment `gunicorn` in `requirements.txt` and install it
5. Run with: `gunicorn "app:create_app()" --workers 4 --bind 0.0.0.0:8000`
6. Put Nginx in front of Gunicorn as a reverse proxy
7. Never commit `.env` to version control — it is in `.gitignore`

## Security Notes

- All school-scoped routes enforce `verify_school_ownership()` — one school
  can never read or modify another school's data
- PlatformAdmin has `school_id=NULL` and cannot access school-level portals
- Deactivated accounts are rejected on every request, not just at login
- Coupon codes exclude ambiguous characters (0, O, 1, I) to prevent mistakes
  when reading printed codes
